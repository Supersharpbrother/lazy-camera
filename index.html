Примечания
    Обозначения
    • до N — максимум fps по данным производителя; серым — не тянет нужную частоту.
    • н/д — производитель не публикует значение.
    • * у мм — посчитано из пикселей и шага пикселя производителя.
    • ANA — производитель обозначает режим как анаморфотный; DSQ — де-сквиз в камере для выбранного коэффициента.
    Источники

        Обозначения
        • F — фокусное расстояние, мм; T — максимальная светосила (T-стоп).
        • МДФ — минимальная дистанция фокусировки, м, от плоскости сенсора (если производитель не оговорил иное).
        • Ø — диаметр передней части объектива под накидной компендиум / clamp-on адаптер, мм.
        • кг — вес по данным производителя (у Cooke — с PL-байонетом).
        • Пятно — диаметр круга изображения по данным производителя; формат — производитель указывает только формат кадра, в расчёте берём его диагональ.
        • н/д — производитель не публикует значение.
